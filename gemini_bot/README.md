# 🤖 Telegram-бот на базе Google Antigravity CLI & Gemini

Продвинутый автономный AI-ассистент в Telegram на базе **Google Antigravity CLI** и **Gemini 3.8**. Превращает Telegram в персональный пульт управления разработкой с поддержкой многопользовательской работы, строгой изоляцией сессий и панелью Администратора.

В проект также включена системная CLI-утилита **`agy`** для прямого запуска агента из любого терминала!

---

## 🌟 Ключевые возможности

### 1. 👥 Индивидуальные изолированные сессии
* **Полная изоляция:** Каждый пользователь Telegram (`user_id`) получает собственный изолированный контекст диалога в SQLite и собственную персональную сессию в Antigravity CLI.
* **Именование сессий:** Сессии агента создаются с индивидуальным тегом `TG_{user_id}_{username}`, исключая любые пересечения.
* **Независимый сброс:** Команда `/reset` очищает контекст только для того пользователя, который её вызвал.

### 2. 👑 Статус и панель Администратора (`/admin`)
Для владельца бота (`ADMIN_ID = 8562721499`) доступна интерактивная панель управления:
* **📊 Статистика в реальном времени:**
  - Количество пользователей и сообщений
  - Число активных сессий Antigravity CLI
  - Текущая политика безопасности
* **🛡 Контроль доступа к Antigravity CLI:**
  - *«Только Администратор»* (по умолчанию): агент с доступом к терминалу и файлам вашего компьютера доступен только вам; для остальных пользователей доступен быстрый режим прямого Gemini API.
  - *«Для всех пользователей»*: переключается в 1 клик прямо из панели управления.
* **📢 Массовая рассылка (`/broadcast <текст>`):**
  - Возможность отправить важное объявление или новость всем пользователям бота с отчетом о доставке.
* **👥 Список пользователей:**
  - Просмотр активности пользователей, выбранных режимов и количества сообщений.

### 3. 🏛 Агент Гермес (Мульти-LLM маршрутизатор)
Интеллектуальный диспетчер запросов, объединяющий ведущие мировые нейросети:
* **Авто-маршрутизация (`auto-hermes`):**
  - 🧮 **DeepSeek R1 / V3:** направляет задачи на доказательство теорем, олимпиадную математику и строгие цепочки рассуждений.
  - 🎭 **Claude 3.5 Sonnet:** направляет задачи на написание чистого кода, архитектурные решения, рефакторинг и аудит ошибок.
  - 🦙 **Nous Hermes 3 / 🟢 ChatGPT:** направляет творческие задания, литературные тексты и генерацию сценариев.
  - ⚡ **Google Gemini 3.5 Flash:** берет на себя быстрые ответы, транскрибацию аудио и мультимодальность.
* **Естественные команды в чате:**
  - `«Гермес, спроси у DeepSeek: реши интеграл...»`
  - `«через Claude: спроектируй структуру базы данных...»`
  - `«Гермес, сочини сценарий...»`
* **Отказоустойчивость и единая память:**
  - Если для сторонней нейросети не задан API-ключ, Гермес плавно перенаправляет запрос на Gemini 3.5 Flash с поясняющим уведомлением без ошибок.
  - Контекст диалога сохраняется при переключении между моделями.

### 4. 🤖 Режим агента Antigravity CLI
* Агент подключен к ядру **Antigravity CLI** (`agentapi`).
* Выполнение задач по разработке, чтение файлов, запуск команд и многошаговое рассуждение.
* Трансляция промежуточных статусов: `🛠 Выполняю: ...`.

### 5. ⚡ Режим прямого Gemini 3.5 Flash
* Моментальные ответы на вопросы, генерация текстов и консультации без запуска тяжелых агентных инструментов.

### 6. 💻 Системная утилита командной строки `agy`
Агент Antigravity доступен прямо в вашем терминале в любой точке macOS:
```bash
# Разовая задача
agy "Проверь структуру проекта todo-student"

# С использованием Pro-модели
agy -m pro "Сделай рефакторинг архитектуры"

# Интерактивный диалог в терминале
agy -i
```

## ⚡ Архитектура «Безлимитный режим запросов» (Anti-429)

Бесплатный тариф Google AI Studio накладывает ограничение по частоте запросов в минуту (RPM). Чтобы бот никогда не блокировался и не выдавал ошибок перегрузки, внедрена трехуровневая система защиты:

1. **🔑 Пул API-ключей (Multi-Key Pool с авто-ротацией):**
   * Вы можете указать несколько бесплатных ключей в файле `.env`:
     ```env
     GEMINI_API_KEYS=key1,key2,key3
     ```
   * Запросы распределяются по принципу Round-Robin.
   * Если один ключ исчерпывает минутную квоту (HTTP 429), он автоматически уходит на паузу (cooldown 65 сек), а запрос мгновенно перенаправляется на следующий доступный ключ.
   
2. **🔄 Каскадное переключение моделей (Model Cascading):**
   * У разных моделей Google **независимые лимиты запросов в минуту**.
   * Если квота текущей модели исчерпана, бот автоматически и бесшовно для пользователя переключается на резервную модель в цепочке:
     `gemini-3.8-flash` ➡️ `gemini-flash-latest` ➡️ `gemini-3.5-flash` ➡️ `gemini-3.1-flash-lite`
   * Это умножает доступный лимит запросов в 4 раза даже при использовании одного API-ключа!

3. **⏳ Адаптивный Exponential Backoff & контекстная оптимизация:**
   * Скользящее окно контекста (Sliding Window) с ограничением токенов предотвращает блокировку по TPM.
   * При пиковых нагрузках бот кратковременно ожидает освобождения квоты и транслирует статус в чат без падений.

## 🛠 Автономная самонастройка (Self-Configuration Engine)

Бот умеет **полностью настраивать себя сам по вашим запросам** на естественном языке (текстом или голосовыми сообщениями) без необходимости редактировать код или перезапускать сервер!

### Примеры запросов для настройки:
* **Стиль общения:**
  * _«Настрой себя так, чтобы ты всегда отвечал кратко и по делу»_
  * _«Сделай стиль ответов развернутым / senior developer / дружелюбным»_
* **Кастомные правила поведения:**
  * _«Добавь правило: в каждом примере кода на Python обязательно использовать type hints»_
  * _«Добавь правило: отвечать на русском языке и на "ты"»_
  * _«Удали правило 1»_ или _«Очисти все правила»_
* **Параметры генерации:**
  * _«Поменяй температуру на 0.2»_ (для точного кода без галлюцинаций)
  * _«Установи температуру 0.9»_ (для творческих идей)
* **Просмотр и сброс:**
  * _«Покажи свои настройки»_ или команда `/config`
  * _«Сбрось настройки к заводским»_

Все изменения мгновенно сохраняются в SQLite базе данных и вступают в силу со следующего ответа!

## 🌐 Развертывание на сервере Render.com (24/7 в облаке)

Бот полностью подготовлен для развертывания на бесплатном тарифе **Render.com Web Service**:
* Встроен легковесный HTTP health-check сервер на порту `$PORT` (по умолчанию 10000).
* Эндпоинт `/health` отдает JSON-статус со временем работы (uptime).
* Главная страница `/` отображает веб-дашборд состояния бота в браузере.
* Включены файлы `render.yaml`, `Dockerfile` и `Procfile`.

### Пошаговая инструкция:

#### 1. Загрузите код в GitHub / GitLab
```bash
git add .
git commit -m "Deploy gemini_bot with Render support and self-config"
git push origin main
```

#### 2. Создайте Web Service на Render
1. Зайдите на [dashboard.render.com](https://dashboard.render.com/) и нажмите **«New +» ➡️ «Web Service»**.
2. Подключите ваш репозиторий GitHub.
3. Заполните параметры сервиса:
   * **Name:** `gemini-telegram-bot`
   * **Region:** Frankfurt (EU)
   * **Branch:** `main`
   * **Root Directory:** `gemini_bot`
   * **Runtime:** `Python 3`
   * **Build Command:** `pip install -r requirements.txt`
   * **Start Command:** `python main.py`
   * **Instance Type:** `Free`

#### 3. Настройте переменные окружения (Environment Variables)
В разделе **«Environment»** добавьте:
* `TELEGRAM_BOT_TOKEN`: токен вашего бота из @BotFather (обязательно)
* `GEMINI_API_KEYS`: ваш API-ключ Gemini (или несколько через запятую) (обязательно)
* `ADMIN_IDS`: `8173946372,8562721499`
* `DEFAULT_MODEL`: `auto-hermes`
* `PORT`: `10000`

**Дополнительные ключи для Агента Гермес (подключайте по желанию):**
* `OPENROUTER_API_KEY`: универсальный ключ для доступа к Nous Hermes 3, Claude 3.5, DeepSeek R1, GPT-4o через OpenRouter
* `DEEPSEEK_API_KEY`: для прямого подключения DeepSeek R1 / V3
* `ANTHROPIC_API_KEY`: для прямого подключения Claude 3.5 Sonnet
* `OPENAI_API_KEY`: для прямого подключения ChatGPT (GPT-4o)

#### 4. Защита от засыпания (Keep-Alive для Free Tier)
Бесплатный тариф Render усыпляет Web Service при 15 минутах без внешних запросов. Чтобы бот работал **непрерывно 24/7**:
1. Скопируйте URL вашего развернутого сервиса (например, `https://gemini-telegram-bot.onrender.com`).
2. Зарегистрируйтесь на бесплатном сервисе [UptimeRobot.com](https://uptimerobot.com/) или [cron-job.org](https://cron-job.org/).
3. Создайте новый монитор типа **HTTP(s)**:
   * **URL:** `https://ваш-сервис.onrender.com/health`
   * **Интервал:** 5 или 10 минут.
4. Сервис будет автоматически пинговать health-check эндпоинт, и бот никогда не уснет!
