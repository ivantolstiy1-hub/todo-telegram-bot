# Мини-планировщик задач (`todo.py`)

Консольное приложение на стандартной библиотеке Python (`sys`, `json`, `pathlib`) для управления списком задач с сохранением в `tasks.json`.

## Формат задачи в `tasks.json`
Каждая задача хранится в виде JSON-объекта:
- `id` — уникальный числовой идентификатор задачи
- `title` — текст задачи
- `done` — статус выполнения (`true` / `false`)

## Быстрый старт и проверка (5 команд)

```bash
# 1. Добавить первую задачу
python3 todo.py add "Купить продукты"

# 2. Добавить вторую задачу
python3 todo.py add "Сделать домашнее задание по Python"

# 3. Посмотреть список задач (обе со статусом ⬜)
python3 todo.py list

# 4. Отметить задачу #1 выполненной
python3 todo.py done 1

# 5. Проверить обновлённый список (задача #1 со статусом ✅)
python3 todo.py list
```
